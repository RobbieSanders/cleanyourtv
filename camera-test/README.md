# Camera Test (experimental)
Independent Android TV application, package com.gathin.cameratest. It does not register as HOME or change any launcher configuration. It uses the public protocol documented by the open-source vivintpy project (https://github.com/natekspencer/vivintpy), not an official Vivint SDK. It supports the legacy system/panel enumeration format only. It performs account authentication and read-only discovery, selects local IPv4 RTSP URLs returned for the authorized account, and plays one stream at a time using Media3. It never changes alarm, camera, recording or privacy settings. It skips cameras reported in privacy mode and does not use external stream URLs. No account or stream secrets are committed or persisted by the app. Do not share login details or RTSP URLs. No background service, events or notifications. Playback and session state are discarded when leaving the activity. Authentication, device enumeration and video playback require real-device verification. The non-debuggable release APK uses a temporary test signing key separate from the launcher. To rebuild, use the Build Camera Test APK workflow; uninstall only this test package if a signature mismatch occurs.
